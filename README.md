🌍 空气质量监控平台
本项目是一个基于 Python 和 Node.js 的空气质量数据抓取与解析工具。它通过模拟请求 的加密接口，获取指定城市的实时空气质量数据（AQI、PM2.5、PM10 等），并自动处理数据的加密与解密逻辑。aqistudy.cn

✨ 功能特性
实时数据获取：获取指定城市的实时空气质量指数（AQI）及各监测点详细数据。
自动加解密：内置对目标网站 AES、DES 及 Base64 加密算法的模拟，自动处理请求参数和响应数据。
多污染物监测：支持解析 PM2.5， PM10， SO2， CO， NO2， O3 等多项指标。
命令行交互：支持终端输入城市名称进行查询。

⚙️ 技术实现原理
本项目采用 Python + Node.js 混合编程的方式解决数据加密问题：
参数生成 (Python -> Node.js):
Python 获取用户输入的城市名。
调用 一.js 生成加密后的请求参数 (param)。该过程涉及 MD5 签名生成和 Base64 编码。
数据请求 (Python):
使用 requests 库向 https://www.aqistudy.cn/apinew/aqistudyapi.php 发送 POST 请求。
携带生成的加密参数及模拟的浏览器 Headers。
数据解密 (Node.js -> Python):
服务器返回加密的文本数据。
Python 调用 二.js 对响应数据进行解密。
解密流程：AES解密 -> DES解密 -> Base64解码。
数据展示 (Python):
解析最终的 JSON 数据并格式化打印。

⚠️ 注意事项
Node.js 环境：由于加密算法较为复杂，本项目依赖本地安装的 Node.js 环境来执行 .js 脚本。如果提示 node 不是内部或外部命令，请检查 Node.js 是否正确安装并配置了环境变量。
城市名称：请输入标准的城市名称，避免输入省份或模糊地名，否则可能导致解析失败。
反爬虫机制：代码中已内置部分 Headers 和 Cookie 模拟，若频繁请求可能会触发反爬机制，建议控制请求频率。
